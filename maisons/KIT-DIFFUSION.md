## 1. Google Search Console — 5 minutes, indispensable

C'est la seule chose qui fait entrer le site dans Google. Personne ne peut le faire à ta place (il faut ton compte Google).

1. Va sur **search.google.com/search-console**, connecte-toi avec contact.sablepierre@gmail.com.
2. **Ajouter une propriété** → **Domaine** → `sable-et-pierre.com` → Continuer.
3. Google propose **« Vérifier avec Cloudflare »** (ou « Démarrer la vérification ») : accepte et connecte-toi à Cloudflare. C'est automatique.
   *Si cette option n'apparaît pas* : copie le code TXT affiché, puis Cloudflare → sable-et-pierre.com → **DNS** → **Add record** → Type `TXT`, Name `@`, Content = le code → Save. Reviens dans Google → **Valider**.
4. Menu **Sitemaps** → tape `sitemap.xml` → **Envoyer**.
5. Menu **Inspection de l'URL** → colle chaque adresse ci-dessous → **Demander une indexation** :
   - https://sable-et-pierre.com/
   - https://sable-et-pierre.com/lacanau
   - https://sable-et-pierre.com/bordeaux
   - https://sable-et-pierre.com/vacances-famille-lacanau
   - https://sable-et-pierre.com/vacances-famille-bordeaux
   - https://sable-et-pierre.com/guide-plages-lacanau
   - https://sable-et-pierre.com/guide-semaine-gironde-famille

Ensuite : **Bing Webmaster Tools** (bing.com/webmasters) → « Importer depuis Google Search Console ». Un clic.

> Bing, DuckDuckGo, Ecosia, Qwant et Yahoo sont déjà prévenus automatiquement à chaque mise à jour du site (IndexNow).

## À ne pas faire

- **Ne mets pas le lien du site dans tes annonces Airbnb** (ni Abritel, ni Booking) : c'est interdit et l'annonce peut être suspendue.
- **Ne contacte pas tes voyageurs Airbnb en dehors d'Airbnb** pour leur proposer la réservation directe : Airbnb l'interdit aussi. En revanche, le livret d'accueil dans la maison peut mentionner le site.
- **Pas de fiche Google Maps (Google Business Profile)** pour les maisons : Google ne les accepte pas pour les locations de vacances.
