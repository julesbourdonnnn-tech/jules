2. L'installer dans Gmail (sur ordinateur)

  1. Sur cette page, cliquez sur « Copier la signature ». Si rien ne se passe, cliquez sur « Sélectionner seulement », puis faites Ctrl + C (ou Cmd + C sur Mac).
  2. Ouvrez Gmail avec nuitssingulieres@gmail.com : roue dentée, puis Voir tous les paramètres, onglet Général, rubrique Signature.
  3. Cliquez sur « Créer », nommez-la « Nuits Singulières », puis collez (Ctrl + V) dans la grande case.
  4. Juste en dessous, choisissez cette signature pour les nouveaux e-mails et pour les réponses et transferts.
  5. Tout en bas de la page, cliquez sur « Enregistrer les modifications ».

3. Sur l'application Gmail du téléphone

L'application n'accepte qu'une signature en texte simple. Copiez celle-ci : Gmail, menu ☰, Paramètres, votre compte, Signature (« Signature mobile » sur iPhone).
